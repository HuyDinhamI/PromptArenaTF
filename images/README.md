# Images Folder

Thêm các file ảnh tham khảo vào thư mục này để sử dụng trong game.

## Formats được hỗ trợ:
- .jpg
- .jpeg 
- .png
- .gif
- .webp

## Lưu ý:
- Ảnh nên có kích thước hợp lý (không quá lớn)
- Nội dung ảnh nên rõ ràng để dễ mô tả bằng prompt
- Đặt tên file có ý nghĩa để dễ quản lý

## Ví dụ ảnh phù hợp:
- Phong cảnh: sunset.jpg, mountain.png
- Động vật: cat.jpeg, dog.png
- Đồ vật: car.jpg, house.png
- Nghệ thuật: abstract.png, painting.jpg

Để bắt đầu, hãy thêm ít nhất 1 file ảnh vào thư mục này.
